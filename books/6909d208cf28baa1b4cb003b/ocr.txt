mehre es 24. Stunden lang / daß der Ofen weißlicht glüe / je länger es stehet je besser es wird / brich hernach den Tiegel auf / so wird der Zeug weiß Glaß seyn / als Milch Farbe / und soll gemahlen und gerieben werden aufn Marmel mit Wasser; bis wie Milch oder Bleyweiß sey. Nachdem soll man Geschirrlein machen von weisser Erden die in Feuer bestehet und gantz weiß wird / als die Dornickische welche Ratgrau ist / und wenn sie gebrannt gantz weiß wird. Diese Geschirrlein soll man auf den Drehe-Klotz oder Banck gantz dünne machen und schaben / auch in Formen trucken / weil sie noch weich seyn / wann sie nun dünne genug worden / so werden sie mit vorbeschrieben Firnuß gantz durchtrünckt und gantz durchscheinig / sonst wo sie dicker / muß man mit derselben Erden ein Sechstel des Gläsern Firnuß oder Glasur nieder arbeiten. Item / so müssen die irrdene Geschirr bevor sie gefirnist / gekocht werden in kleinen Feuer / in einen Futter / darinn jedes Geschirrlein geschlossen stehe / auf 3 Fuß oder Spizlein / von selbiger weissen Erden / und muß jenes Futter von Namurischer Erden seyn / und alle Fugen wohl verstopft haben / wanns nun also mit dunckler Glut 24. Stunden gekocht / soll man die Töppf oder Geschirrlein ausnehmen und schabe sie nachdem es von nöthen ist / und firnisse sie mit vorgedachten Milch-Pulver mit Wasser gemenget / also / daß das Wasser davon lauffe / und soll das Glasur so dick seyn als ein halber Reichs-Orth / um die Geschirr zu durchdringen / und wann sie trucken / soll man sie mahlen mit Schmelz oder Blau Ratzer darum legen / auf den Drehe-Block oder Banck / als gleich Chinesische Figuren und Geschirr. Sobald sie wieder getrucknet / soll man sie wie zuvor wieder in ihr Futter packen / und das allerheffeste Feuer / als möglich ist / von Holtz geben / dann je heisser das Feuer ist / je weisser die Geschirr werden.

*Plurima Pars abhorret, quoniam aliorum ipsos vestigia terrent, & Ars osores obtinuit ignorantes & incredulos hinc, imo impugnantes.
