# 安帝
名祐。肅孫。十三歲即位。太后政。入繼大統。在位十九年。壽三十一。改元者五：永初七、元初六、永寧一、建光一、延光四。

# 北鄉侯
名懿。章帝孫。濟北王惠王壽子。閻后立之。后遂聽政。立二百七十二日。而崩。

# 順帝
名保。安帝子。以入繼大統。在位十九年。壽三十三。改元者五：永建六、陽嘉四、永和六、漢安二、建康一。

# 沖帝
名炳。順帝子。三歲。改元者一：永嘉一。梁太后立之。臨朝聽政。在位一年。壽三。

# 質帝
名纘。章帝曾孫。梁太后迎。勃海孝王之子。入繼大統。在位一年。梁冀鴆之。壽八。改元者一：本初一。

# 桓帝
名志。章帝曾孫。以蠡吾侯入繼大統。誅梁冀。在位二十一年。壽三十七。改元者七：建和三、和平一、元嘉二、永興二、永壽三、延禧九、永康一。

# 靈帝
名宏。章帝曾孫。竇太后迎。解犢亭侯入繼大統。十三歲即位。太后臨朝。在位二十二年。壽三十四。改元者四：建寧四、熹平六、光和六、中平六。

# 少帝
名辯。靈帝子。立百七十日。為董卓廢而弒之。

# 獻帝
名協。靈帝次子。董卓立。在位三十一年。
