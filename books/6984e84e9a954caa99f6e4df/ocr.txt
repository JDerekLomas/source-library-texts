# PARADOXA
## MONETARIA.

### I.
**D**as heutiges tages Ehrliche leute / wenn sie schon nicht zu Schelmen werden wollen / nothwendig müssen Schelmen sein / denn wer nicht wechselt / muß pancrottieren.

### II.
Das / obgleich die Paracelsisten für ein Mysterium halten auß Kupffer Silber machen / es doch alle Müntzer wissen.

### III.
Das ein Geldtragender Bote zu diesen zeiten so viel presiren kan / als ein Roß vor 5. Jahren.

### IV.
Das einer der vor 30. Jahren ein tausent verliehen / mag mit guten gewissen zehen tausent wieder fordern / und wird doch nit reicher / besonder leidet schaden.

### V.
Das ein armer Wechsler mehr hat / als ein reicher Edelmann.

### VI.
Das die Müntzer das Gold auff den Kleidern / die Edelleute Kupffer im Beutel tragen.

### VII.
Das / der verfluchten Müntzerkunst nach / Elisæus ein schlecht Miracul verrichtet / dann heutiges tages das Kupffer ohn einen Propheten auffm Wasser woll schwimmen kan.

<sig>A 2</sig>
VIII.
